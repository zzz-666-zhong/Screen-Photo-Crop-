# Screen-Photo-Crop-
从拍摄的屏幕照片中提取屏幕内的完整图片，自动定位四角、校正透视并保留暗色内容。内置已训练模型，支持批量处理、逐张审核、手动裁剪和当前图片重新裁剪。  Extract complete pictures from photographed screens with automatic corner detection, perspective correction, and dark-content preservation. Includes a pretrained model, batch processing, review, manual cropping, and re-cropping the current image.
