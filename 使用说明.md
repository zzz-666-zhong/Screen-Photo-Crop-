# 使用说明 / Usage

逐张审核可点击“改用黑边 / Use frame”重算当前图片，也可点“改用边缘 / Use edges”切回。只影响当前图片，下一张沿用批次原算法；切换不自动保存，找不到边界时保留原选区。

During Review, Use frame/Use edges re-detects the current image with the selected algorithm. This image alone is affected; the next uses the batch default. Switching never saves automatically and failed detection preserves existing points.

普通自动识别优先使用图片边缘；未找到边界时才参考黑框，专用黑边模式仍以细黑框为主。

Normal automatic detection uses picture edges first and thin frames as a fallback. Black-border review remains frame-first.

审核时可在“拍摄失败 / Reject”旁选择原因再点击按钮，原照片会复制到结果目录“拍摄失败”并写入“拍摄失败记录.csv”。表格可用 Excel 打开，包含路径、原因、时间和状态。右侧可筛选“拍摄失败”，双击回看；输入原图保留，自动识别失败不会自动当成拍摄失败。

Select a reason and click Reject to copy the source into the result folder's 拍摄失败 directory and update the Excel-readable 拍摄失败记录.csv with paths, reason, time and status. Filter Rejected and double-click to revisit. Input originals are kept; detection errors alone are not capture rejections.

逐张确认时会后台准备下一张，预览下方显示是否准备完成。最后一张确认后，等待顶部从“正在保存与整理”变为“已完成”即可返回设置。保存期间可以请求暂停、结束或关闭，程序先完成当前写入。PNG 保持无损，快速保存可能使文件略大。

Review prepares the next image in the background and shows its readiness below the preview. After the final confirmation, wait for Complete before starting another batch. Pause/Stop/Close requests during saving take effect after the active write. PNG stays lossless; faster saving may produce larger files.

裁剪页面右侧显示图片列表和已裁、未裁、草稿、跳过、失败及处理进度；筛选“未裁剪”可查看没有成功输出的照片，双击跳转。进度条按实际已有裁剪结果计算；外部增删结果后可点击“刷新”。

The crop page lists images and cropped, uncropped, draft, skipped, error, and processed counts. Filter No crop and double-click a row to navigate. The progress bar counts actual output files; Refresh rescans after external changes.

黑边识别确认：在设置页选择“黑边识别 · 逐张确认”。识别中间图片的细黑框后，检查右侧预览，放大或拖动四角调整，按 Enter 才保存下一张。无可信边框时可手动选四点；默认保留图片内部暗色内容。命令：`python screen_crop.py "原图" "结果" --black-review --square`。

普通自动模式也可识别文字图片和细黑框。手动四角、失败补裁中可点“识别边界 / Detect”获得建议，识别失败时保留原有选点。固定坐标模式仅识别首张，确认后按同一坐标处理后续照片；请确保位置不变。

Normal detection also supports text images and thin dark frames. In Manual or Retry, click Detect for a proposal; failed detection preserves existing points. Fixed mode detects the first image and reuses its confirmed coordinates, so later images must have the same framing.

Black-border review: choose the mode on the startup page, inspect the proposed picture frame and preview, zoom/adjust corners, then press Enter to save each image. Pick corners manually if no reliable frame is found. Dark photographic content is retained by default. CLI: `python screen_crop.py "input" "output" --black-review --square`.

完整中英文操作说明见 [docs/USAGE.md](docs/USAGE.md)，包括固定坐标批量导出、审核、手动裁剪、结果预览、放大拖移、上一张、暂停续裁及训练标签导出。

See [docs/USAGE.md](docs/USAGE.md) for bilingual instructions, including fixed-coordinate batch export, review, manual cropping, preview, zoom/pan, Previous, Resume, and training-label export.

固定坐标模式：选择“固定坐标”，在首张照片检查或重选四角，按 Enter 一次；后续自动按相同坐标导出，无需审核。要求照片尺寸和目标位置一致，支持暂停和恢复。命令示例：`python screen_crop.py "原图" "结果" --fixed --square`。

Fixed coordinates: select Fixed, check or reselect corners on the first photo, and press Enter once. Later photos export automatically without review. Source dimensions and target position must match; pause/resume is supported. Example: `python screen_crop.py "input" "output" --fixed --square`.

Windows 可直接双击 `启动裁剪.cmd`，首次启动会自动准备独立环境；`安装环境.cmd` 可只安装环境。详细说明见 [README.md](README.md)。

On Windows, double-click `启动裁剪.cmd`; first launch automatically prepares the isolated environment. `安装环境.cmd` performs setup only. See [README.md](README.md) for details.
