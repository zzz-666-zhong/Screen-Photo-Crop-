# 参与贡献 / Contributing

欢迎提交问题和改进。先阅读 [README](README.md)、[使用指南](docs/USAGE.md) 和 [模型说明](docs/MODEL_CARD.md)。

Issues and contributions are welcome. Start with the [README](README.md), [usage guide](docs/USAGE.md), and [model card](docs/MODEL_CARD.md).

## 开发与检查 / Development and checks

```powershell
python -m venv .crop-env
.\.crop-env\Scripts\python.exe -m pip install -r requirements.txt
.\.crop-env\Scripts\python.exe -m unittest discover -s tests -v
.\.crop-env\Scripts\python.exe scripts/build_release.py
```

macOS/Linux 使用 `.crop-env/bin/python`。测试使用标准库 `unittest`，不额外依赖 pytest。测试图片由代码合成，手动窗口通过模拟四角返回值验证保存流程，不会在 CI 中打开桌面窗口。

Use `.crop-env/bin/python` on macOS/Linux. Tests use standard-library `unittest`, with no pytest dependency. Images are generated synthetically. Manual workflows mock corner selection to test saving without opening desktop windows in CI.

修改识别逻辑时，请检查暗色内容保留、透视四角顺序、失败重试以及已存在结果跳过等行为。新增候选评分特征时，必须同步元数据和模型，并说明训练/验证分组与评估限制。

When changing detection, check dark-content preservation, corner ordering, failure retries, and existing-output handling. Feature changes require matching metadata and weights, with documented training/validation splits and evaluation limitations.

## 问题反馈 / Reporting an issue

提供 Python/OpenCV 版本、完整命令、预期行为、实际行为，以及相关报告行。图片不是必填项；可优先使用 `examples/generate_demo.py` 生成的合成场景复现。

Include Python/OpenCV versions, the command, expected and actual behavior, and relevant report rows. An image is optional; prefer reproducing with the synthetic scene generated by `examples/generate_demo.py` when possible.

## 提交修改 / Submitting changes

保持修改范围集中，说明变更原因和执行过的检查；涉及文档时同步中文与英文。新增应公开发布的文件时，将其加入 `release-files.txt`。普通输出与实验数据保持在忽略目录内。

Keep changes focused, explain their purpose and validation, and update both documentation languages. Add new distributable files to `release-files.txt`. Keep normal outputs and experimental data in ignored directories.

提交贡献即表示你同意以本项目的 [MIT 许可证](LICENSE) 提供该贡献。

By submitting a contribution, you agree to provide it under the project's [MIT license](LICENSE).
